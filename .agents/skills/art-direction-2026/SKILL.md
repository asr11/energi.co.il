# 🎨 2026 Art Direction & UI/UX Design System Skill

This skill provides state-of-the-art 2026 design principles, visual hierarchy guidelines, and UI/UX execution standards for web applications and WordPress digital assets.

## 🌟 Core Pillars of 2026 Design

### 1. Intentional & Calm UX
- **Clarity Over Theatrics**: Interfaces must be calm, functional, and purposeful. Eliminate unnecessary visual noise.
- **Micro-Animations (<400ms)**: Smooth, inertia-based spring transitions that clarify cause-and-effect (e.g., subtle button compressions, state-aware feedback).

### 2. Modern Layouts & Bento Grid Architecture
- **Max Container Width**: Standardized 1400px centered max-width container (`margin: 0 auto`).
- **Bento Grid Structures**: Asymmetric, card-based layouts with subtle 1px border highlights (`#e2e8f0`) and soft shadows (`box-shadow: 0 4px 6px -1px rgba(0,0,0,0.05)`).
- **Pixel-Perfect RTL**: Complete native right-to-left layout balance for Hebrew typography.

### 3. Adaptive Color Theory & Dark/Light Logic
- **Primary / Accent Tokens**:
  - Deep Authority: `#0d3b66` (Primary Navy)
  - Eco Energy: `#10b981` (Vibrant Green)
  - Warm Neutral: `#f8fafc` (Background Light)
  - Dark Slate: `#0f172a` (High Contrast Text/Footer)
- **High Contrast**: Ensure a minimum contrast ratio of 4.5:1 for body text and 3:1 for large headings.

### 4. Typography & Editorial Design
- **Google Fonts Hierarchy**:
  - Headings: `Rubik` (Bold 600/700, line-height 1.3)
  - Body: `Assistant` or `Inter` (Regular 400, Semi-Bold 600, line-height 1.7)
- **Variable Font Sizing**: Fluid typography scaling from mobile (16px) to desktop (18px-20px).

### 5. Statutory Accessibility & Machine Experience (MX)
- **WCAG 2.2 AA Standards**: 24x24px minimum touch targets, clear focus rings, and screen-reader semantics.
- **Machine Experience (MX)**: Semantic HTML5 elements (`<header>`, `<nav>`, `<article>`, `<aside>`, `<footer>`) to optimize AI indexing (AEO/GEO).
